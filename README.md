# Database-using-MongoDB
A database created for a project, the objective was to create a system for a games company to save data from its directors, workers, and department, where the workers can be divided in artists, musicians and programmers. The software used to make such was MongoDB.
The following files are JSON files os each datas from the collections of diretor(diretor), worker(funcionário) and department(departamento).
The words are written in portuguese, it's recommended to search the words for each to get a better understanding on how it works.
